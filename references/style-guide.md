## A 分支的颜色锚点

以下色值是视觉估计，不是实测或唯一色表；只用于与参考色调接近的原照片。B 分支从目标照片自身提取颜色关系。

| 角色 | 近似方向 |
| --- | --- |
| 纸底 | 暖米白 `#E8E2CF` |
| 中亮蓝 | 柔和钴蓝 `#4B88B2` |
| 青蓝 | `#397F99` |
| 深蓝 | `#24547C` |
| 核心高光 | 奶油白 `#FFF0D7` |
| 高光边缘 | 极浅桃 `#EBC7AF` |
| 红色点缀 | 珊瑚/砖红 `#CA624B` |
| 绿色 | 灰橄榄 `#69754A` |

不要机械替换像素，也不要限制为两种油墨；参考有多层颜色。B 分支不必使用此表。

## 内容适配与验收情形

| 输入 | 预期行为 |
| --- | --- |
| 蓝色海水、有反光 | A；按原反光位置形成奶油白碎光、轻桃色边缘，不能添加参考中的花草 |
| 橙红夕阳、暖色海水 | B；保留橙红、金黄及原阴影色，只迁移颗粒和反光形态，不能变蓝色海景 |
| 阴天白猫 | 根据环境选色；保留左右花纹，白毛连续，无碎光亮片；眼睛和脸清楚 |
| 红黄食物或粉紫花 | B；保留食物/花朵的主色和颜色比例，不强加蓝色阴影，细颗粒不显脏 |
| 暖棕室内人物 | B；保留肤色、五官比例和暖色照明，皮肤亮面不做水面碎光 |
| 绿色植物，角落有小块蓝天 | 通常 B；不能因为小块蓝色改变整个绿色主体，保留自然绿的层次 |
| 冷色建筑，红色商品为焦点 | A 或谨慎保留原色；蓝灰环境可匹配参考，红色焦点保持辨认，不把商品变蓝 |
| 黑白照片 | 默认保留黑白或极轻暖纸底，仅迁移材质，不无依据彩色化 |
| 不同画幅的三张照片 | 三张独立输出，保留方向；颗粒和纸感协调，色彩各自按 A/B 判断 |
| 暗景、无明显高光 | 保持原光线，颗粒清晰但不粗脏，不新增太阳、水光或星星 |

这些是后续使用的检查情形，不表示已执行过生成测试。
